# Student Management Portal

A comprehensive Flask-based student admission and registration portal featuring multi-step application tracking, document uploads, secure OTP verification, and administrative dashboard views.

## Features
* **Multi-Step Registration Flow:** Personal details, academic qualifications, address records, family details, and document uploads.
* **Secure Authentication:** Email OTP verification and hashed passwords.
* **Role/View Modes:** Ability for administrators or students to view completed applications in read-only formats.
* **Printable Application Form:** Direct browser-to-PDF formatting layout optimized for A4 output.

## Tech Stack
* **Backend:** Python, Flask, Flask-SQLAlchemy
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript, Jinja2 Templates, Bootstrap 5, FontAwesome
